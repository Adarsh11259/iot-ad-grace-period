# Data

`profile_traces_combined.csv` is a flattened, per-packet feature table
generated by `scripts/preprocess_pcaps.py` from the raw `.pcap` captures in
the IoT-AD authors' own repo:
[Hasniuj-Zahan/IoT-anomaly-detector](https://github.com/Hasniuj-Zahan/IoT-anomaly-detector),
folder `Dataset/Profile trace/` (23 normal device captures + `anomaly.pcap`).

The raw `.pcap` files themselves are not duplicated here — only this
project's own derived CSV is included, so results are reproducible without
re-running the packet parser. To regenerate it from scratch:

```bash
git clone https://github.com/Hasniuj-Zahan/IoT-anomaly-detector.git
python scripts/preprocess_pcaps.py \
  "IoT-anomaly-detector/Dataset/Profile trace" \
  data/profile_traces_combined.csv
```

Columns: `Time, SourceIP, DestinationIP, Length, DestinationPort,
FlagValue, DeviceLabel, IsAnomaly, SourceFile`. `IsAnomaly` is 1 only for
rows from `anomaly.pcap`; every other file is a normal device and labeled 0.
